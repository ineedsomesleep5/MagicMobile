## Reviewed improvements

- Commander color identity comes from pinned XMage, including both faces, not a front-face text heuristic.
- Curated role data is a hash-pinned, versioned snapshot reproducible in a clean checkout.
- Conservative role fallback excludes quoted, conditional and modal effects. Accuracy checks reject
  missing fixture cards and unintended roles, not just missed positive tags.
- Collection controls scroll on short landscape screens. Collection and deck thumbnails stay visible;
  keyboard submission dismisses the keyboard, quantity changes have accurate feedback, and empty filters
  offer a reset. Artwork preferences explain their app-wide privacy scope in an expandable disclosure;
  the landscape collection toolbar stays compact. The entire search result label opens card inspection.
- Recovery failures explain why closing cannot preserve a draft. Online reference search remains accessible
  when the local catalogue fails to load.
- Phone landscape uses the navigation bar for workspace switching and card count, with no separate deck
  header/tab strip. Secondary controls live in labelled menus; section headers scroll away. A populated
  seven-card UI regression checks usable list height, visible cards and scrolling to the bottom.
- Shared card-rules rendering uses inline mana/tap/untap icons with offline fallbacks and spoken
  accessibility labels. Unknown tokens remain literal; hidden-text normalization is unchanged.
- Catalogue search ranks exact names, name prefixes and other name matches ahead of rules-text mentions
  before result limits and after commander-identity bucket merging. This fixes common lands disappearing
  behind cards that mention them. All filters still apply.
- TestFlight distribution validates the exact processed build, both audiences and Beta App Review state.
  Retries preserve existing review submissions. Apple approval is separate from submission.

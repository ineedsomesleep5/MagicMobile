## Changes and boundaries

- Routine portrait decisions stay in the bottom strip; mana/source actions remain
  card-local. Full engine choices remain available for complex prompts.
- A card with multiple exposed actions always opens a chooser; only an
  unambiguous card action can run directly. Cancel/submit clears selection so
  retapping reopens the current chooser.
- Every player's supplied public zones can be inspected. Named exile, companion,
  revealed/looked-at groups, multiple card actions, and authorized zone targets have
  explicit routes. Piles show supplied contents before choosing. Stack/pile card
  inspection occurs inside the active modal, not behind it.
- One opponent battlefield remains visible in both orientations. Focus never
  changes viewer, action or target identity. Current authorized projections refresh
  inspections; absent private cards are not reconstructed from counts.
- Display-only markup cleanup preserves command tokens. Phase names are readable,
  full detail text can wrap, and a short nonblocking turn cue respects Reduce Motion.
- Skip menu distinguishes safe end-turn, end-turn including stack responses, and
  skipping responses until the viewer's next turn. Aggressive modes are explicitly
  selected, capped at 120/180 seconds and 256 passes, and always stop for mandatory
  choices. Stop skipping, manual input, background, failure and session changes
  cancel scheduling. These modes are currently enabled for the local-human/AI
  route only, not Game Center sessions.
- Manual responses wait for an in-flight poll and revalidate the original prompt;
  they do not retarget a stale command or overlap poll/respond calls.
